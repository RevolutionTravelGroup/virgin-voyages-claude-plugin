# Revolution Travel: Claude plugins

Claude plugins from Revolution Travel, a Canadian travel agency specializing in Virgin Voyages (operating under The Travel Agent Next Door Inc., TICO #5003172).

| Plugin | What it does |
|---|---|
| [revolution-travel-virgin-voyages](plugins/revolution-travel-virgin-voyages) | Live Virgin Voyages sailings and cabin pricing in Canadian dollars, with Bar Tab and Agency Loot, from a public read-only MCP server. |

## Install

In Claude Code:

```
/plugin install revolution-travel-virgin-voyages --marketplace RevolutionTravelGroup/virgin-voyages-claude-plugin
```

In Claude (web or desktop), you can also add the server directly: Settings, then Connectors, then Add custom connector, with the URL `https://virginvoyages.revolutiontravel.ca/api/mcp`.

Revolution Travel is an independent travel agency; it is not Virgin Voyages.
